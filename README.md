# Sui

Software-engineering skills. `sui` routes a request to the one skill the change needs.

---

## Skills

- `sui` routes the request
- `sui-discovery` scopes the outcome
- `sui-architecture` chooses the design
- `sui-implementation` makes the change
- `sui-review` reviews the diff
- `sui-testing` tests the behavior
- `sui-debugging` finds the cause
- `sui-delivery` prepares the release
- `sui-reliability` checks failure and recovery
- `sui-security` checks the trust boundary
- `sui-ai-systems` evaluates a model as a component
- `sui-evidence` checks a technical claim
- `sui-maintenance` changes an existing codebase
